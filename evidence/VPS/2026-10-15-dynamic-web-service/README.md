# Bằng chứng Web Service động trên VPS

Bộ này ghi lại lần nghiệm thu luồng Git → build image → chạy container → định tuyến hostname → restart trên VPS Debian 12, sau đó xác minh hostname công khai và một sản phẩm độc lập ngày 15/10/2026.

- `environment.md`: môi trường và phiên bản kiểm thử.
- `test-record.md`: bảng đầu vào, thao tác, kỳ vọng và kết quả.
- `result.txt`: kết quả kỹ thuật đã lược bỏ bí mật.
- `conclusion.md`: kết luận và giới hạn còn lại.

Không lưu mật khẩu quản trị, cookie phiên, token Cloudflare hoặc khóa SSH.
