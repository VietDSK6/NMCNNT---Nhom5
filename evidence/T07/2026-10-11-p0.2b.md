# T07 — Ranh giới quản trị P0.2B

Ngày kiểm tra: 11/10/2026.

## Kết quả

- POST action khi chưa đăng nhập: HTTP 401.
- Action `exec` ngoài JSON Schema của Control API: HTTP 400.
- Gọi API quản trị Runner không có secret: HTTP 401.
- Version `latest` không có trong catalog: operation `failed`, không thay container.
- Docker socket chỉ xuất hiện trong mount của service `runner`.
- `gateway`, `dashboard`, `control-api`, `app-a`, `app-b` không có Docker socket.
- Runner không có port binding ra host; Gateway vẫn là cổng duy nhất.
- Control API và Runner cùng ngăn operation song song trên một ứng dụng.

## Kết luận

T07 đạt trong phạm vi lab P0.2B. Kết quả chứng minh API quản trị có xác thực và Runner giới hạn input tốt hơn việc nhận command tùy ý. Kết quả không chứng minh Docker socket an toàn nếu chính Runner bị chiếm quyền; đây vẫn là rủi ro đặc quyền cao phải nêu trong báo cáo.
